# Faylasoof-AI-Database

هذه الحزمة تضم 10 قواعد حوار + ملف مستقل لميرفت.

- 01 إلى 10: قواعد الحوار، بإجمالي 1,000,000 سجل.
- 11_ميرفت.json: ملف مستقل لمعلومات ميرفت وقواعد التحقق والحفظ.
- ملف الفهرس يوضح محتويات المستودع.

مهم: ملف ميرفت لا تُضاف إليه معلومات جديدة إلا بعد نجاح التحقق من هوية المتحدث وفق القواعد الموجودة داخله.
